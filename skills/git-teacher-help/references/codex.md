# Codex에서 실행할 때 (git-teacher 전 스킬 공통)

SKILL.md 절차는 그대로 따르고, 아래 차이만 적용한다. 플러그인 루트는 SKILL.md에서 두 단계 위 폴더이고, 본문의 `${CLAUDE_PLUGIN_ROOT}`는 이 루트로 바꿔 읽는다.

## 질문 = 질문 도구 (이번 세션 도구 목록으로 판단)

1. `request_user_input_async`가 있으면 `AskUserQuestion` 1콜 = 이 도구 1콜(문항 ≤4개).
   - 형식: `{"questions":[{"title":"헤더 — 질문","options":["추천안 (추천) — 설명","대안 — 설명"]}]}`
   - 문항에는 `title`·`options`(문자열 배열)만. `question`·`header`·`id`를 넣으면 파싱 오류가 난다.
   - 추천안을 맨 앞에. "기타·직접 적기"는 넣지 않는다(자유 입력 칸이 자동으로 붙는다). `multiSelect`는 제목 끝에 "(여러 개면 쉼표로)".
   - 부른 뒤 "위 질문에 답해 주시면 이어서 진행합니다" 한 줄만 쓰고 턴을 끝낸다. 답은 다음 사용자 메시지로 온다.
2. Plan 모드라 `request_user_input`만 있으면: 1콜 3문항까지. `header`(12자 이내)·`id`(snake_case)·`question`, 선택지 2~3개(`label`·`description`), 추천 라벨 끝에 `(Recommended)`.
3. 둘 다 없으면 채팅에 번호 블록으로 낸다(추천안은 1번, "모르면 1번으로 진행할게요" 한 줄):

```text
질문: <한 줄 질문>
1. <추천안> — 무엇인지, 트레이드오프
2. <대안> — 무엇인지, 트레이드오프
3. 문장으로 직접 수정 요청
```

4. `codex exec`처럼 사람이 답할 수 없는 실행이면 묻지 않고 안전한 기본값으로 진행한다. 저장 제외·되돌리기·push처럼 되돌리기 어려운 동작은 기본값으로 실행하지 않고 멈춰서 안내만 한다.

## 이 플러그인만의 차이

- 선택지 문구는 SKILL.md의 JSON 예시(`label`·`description`)에서 가져와 `title`·`options` 문자열로 옮긴다. 충돌 덩어리 선택(내 쪽 / 상대 쪽 / 둘 다)도 같다.
- 질문 도구에는 프리뷰가 없다. 보여 줄 예시는 도구를 부르기 직전 채팅에 짧게 먼저 쓴다.
- 첫 실행 설정(`setup/setup.sh`)은 Claude Code 전용이다. Codex에서는 아무것도 하지 않는다.
- 교육 원칙의 첫 질문("지금 ~을 어떻게 이해하고 계세요?")은 도구 없이 열린 채팅 질문으로 던진다.
- 다른 스킬로 넘기라는 지시(예: 인자 분기, "되돌리기 스킬로 안내")는 해당 `skills/<이름>/SKILL.md`를 열어 그 절차를 따른다.
- Claude Code의 `/rewind`는 Codex에 없다. undo 스킬의 `/rewind` 비교 설명은 "에이전트 체크포인트 기능이 있는 도구에서만 해당"이라고만 짧게 안내한다.
