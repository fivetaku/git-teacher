## クイックスタート

### 1. マーケットプレイスを追加（最初の一度だけ）

```
/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
```

### 2. プラグインをインストール

```
/plugin install git-teacher
```

### 3. Claude Code を再起動

プラグインを読み込むには再起動が必要です。

### 4. セットアップを開始

```
/git-teacher 시작
```

または、こう話しかけるだけでも OK：`"깃 시작해줘"`（Git を始めて）——このプラグインは自然言語を理解します。

### 5. 5 ステップの流れに従う

```
ステップ 1 + 2: セットアップ   → ツールをインストールし、プロジェクトフォルダを作成（一度だけ）
ステップ 3: 保存               → "저장해줘"   （変更をコミット）
ステップ 4: アップロード       → "올려줘"    （GitHub にプッシュ）
ステップ 5: レビュー依頼       → "검토 요청해줘"  （プルリクエストを作成）
```

## なぜ git-teacher？

- **コマンドの暗記が不要** —— やりたいことを普段の言葉（韓国語）で言えば、あとはプラグインが判断します
- **たとえ話ファーストの説明** —— すべての概念を開発者用語ではなく、Google Drive・Dropbox・iCloud にたとえて説明
- **済んだことはスキップ** —— セットアップが現在の状態を検出し、本当に必要なステップだけを実行
- **Git の出力を翻訳** —— `fatal: not a git repository` の代わりに「이 폴더는 Git 프로젝트 폴더가 아니에요（このフォルダは Git プロジェクトフォルダではありません）」と伝えます
- **難しい部分もお任せ** —— マージコンフリクト、detached HEAD、stash——平易な言葉で説明し、明確な選択肢を提示

## 仕組み

Git と Google Drive の核心的な違いはひとつだけ：**何も自動では同期されない**こと。保存もアップロードも、すべて手動のステップです。それさえ分かれば、あとは自然についてきます。

```
ファイルを編集する
       │
       ▼
  保存（Commit）             ← "저장해줘"
  変更をひとまとめに記録
  まだ自分のマシンの中だけ
       │
       ▼
  アップロード（Push）       ← "올려줘"
  GitHub のクラウドへ送信
  これで他の人にも見える
       │
       ▼
  レビュー依頼（PR）         ← "검토 요청해줘"
  「チームのみんな、これ見て」
  Google Docs の提案モードのようなもの
```

### Google Drive との比較

| Google Drive | Git | 重要な違い |
|---|---|---|
| アプリをインストール | Git + GitHub CLI をインストール | 同じ —— 始めるにはアプリが必要 |
| Google アカウントでログイン | GitHub アカウントを連携 | 同じ —— クラウドにはアカウントが必要 |
| 共有フォルダを作成 | リポジトリを作成 | 同じ —— ファイルを入れるフォルダ |
| ファイルは自動で同期 | **ファイルは自動では同期されない** | **ここが最大の違い** |
| 「編集を提案」モード | Pull Request | 似ている —— 「こう変えたので確認してください」 |

> いちばん大事なこと：Google Drive は自動同期しますが、Git はしません。保存（commit）とアップロード（push）は自分でやる必要があります。忘れると、作業は自分のマシンにしか残りません。

## 機能

### コマンド

| コマンド | 何をするか |
|---|---|
| `/git-teacher` | 何をするか選ぶメニューを開く |
| `/git-teacher 시작` | セットアップ：ツールのインストール + プロジェクトフォルダの作成 |
| `/git-teacher 상태` | ステータス：最後の保存から何が変わった？ |
| `/git-teacher 저장` | 保存：変更をローカルにコミット |
| `/git-teacher 올리기` | アップロード：コミットを GitHub にプッシュ |
| `/git-teacher 검토` | レビュー：プルリクエストを作成 |
| `/git-teacher 도움말` | ヘルプ：Git 用語をたとえ話で説明 |

### 自然言語トリガー

スラッシュコマンドを使わなくても、こんなフレーズで動きます：

| やりたいこと | こう言う |
|---|---|
| 初回セットアップ | "깃 시작해줘"、"깃 설정"、"처음이에요" |
| 現在の状態を確認 | "지금 어떤 상태?"、"뭐가 바뀌었어?" |
| 変更を保存（Commit） | "저장해줘"、"커밋"、"세이브" |
| GitHub にアップロード（Push） | "올려줘"、"푸시"、"업로드" |
| レビュー依頼（PR） | "PR 만들어줘"、"검토 요청해줘" |
| 用語について質問 | "commit이 뭐야?"、"push랑 commit 차이" |

### スキル

| スキル | フェーズ | 説明 |
|---|---|---|
| `git-teacher-setup` | 1–2 | Git のインストール、GitHub の連携、プロジェクトフォルダの作成 |
| `git-teacher-status` | — | `git status` を平易な言葉に翻訳 |
| `git-teacher-save` | 3 | 変更を自然言語の要約付きでコミット |
| `git-teacher-upload` | 4 | コミットを GitHub にプッシュ |
| `git-teacher-review` | 5 | プルリクエストを作成 |
| `git-teacher-help` | — | クラウドのたとえを使った用語集 + FAQ |

### ヘルプシステム

`git-teacher-help` スキルは、こんな質問に答えます：

- "commit이 뭐야?"（commit って何？） → 一行要約 + Google Drive のたとえ
- "push랑 commit 차이?"（push と commit の違いは？） → 比較表
- "Git 작업 흐름이 어떻게 돼?"（Git の作業フローはどうなってる？） → 全体の流れを平易な言葉で図解
- "fatal: not a git repository 이게 뭐야?"（これは何？） → 翻訳 + 次にやることの案内
